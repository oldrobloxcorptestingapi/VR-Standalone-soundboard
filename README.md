# VR-Standalone-soundboard
an soundboard that work on meta quest ANDROID AND WINDOWS ONLY

How to setup
# Download the .exe file in releases on this repo of OUSOURCE ENGINE
this will get you the server
# Make Sure To Go To The Server Tab

## Step 2
# Key Mapper (REQUIRED)
then get your computer IP then
setup an http request to IP:3000/your-route
routes help you set sounds

## Step 3
# Voicemod Key Required
this needs your phone plugged into your
headset with an 3.5mm audio jack to type-c adapter
then connect your android phone to your pc using adb
## ADB IS ANDROID-TOOLS DOWNLOAD FROM OFFICAL ANDROID SITE

## Step 4
# IF YOU GET AN IO ERROR HERES HOW TO FIX IT
1. run adb diconnect then reconnect your device
with adb connect IP:PORT
## USE YOUTUBE MUSIC FOR AUDIO PLAYBACK
2. make sure to put the correct destation of the audio file
## DO NOT REMOVE SDCARD part out of the file location this is REQUIRED
